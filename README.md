## 🚀 Aperçu & Fonctionnalités du Portfolio

Ce site web portfolio interactif et ultra-moderne met en valeur mes compétences techniques, mes projets en cybersécurité et mes certifications :

- 🎨 **Design Cyber-Defense Dark/Light Mode** : Thème sombre inspiré des consoles SOC/Sec-Ops avec glassmorphism, effets néon, micro-animations CSS3 et switch Mode Clair / Mode Sombre.
- 🛡️ **Centre de Supervision SOC (Blue Team & SIEM)** : Visualisation interactive des outils SOC (Wazuh SIEM, pfSense, Suricata, Splunk, Elastic SIEM, Active Response, MITRE ATT&CK).
- 📂 **Showcase des Projets (13 Projets Réels)** : Filtres dynamiques par catégorie (Cybersécurité & SOC, Blockchain & Web3, Développement Web, Applications Desktop Java).
- 📜 **11 Certifications Homologuées & Vérifiées** : Cartes interactives avec identifiants et liens officiels de vérification Coursera / Google / Meta / EPFL.
- 📄 **Visionneuse de CV Intégrée** : Modale interactive permettant de lire et téléchoisi le CV sans quitter le site.
